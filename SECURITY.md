# Security policy

This repo is a static website — no backend, no user accounts, no secrets. If you
find a security issue in the site itself (or in how it is built and deployed),
please report it privately to **michael@hohlios.com** rather than opening a
public issue. We'll acknowledge within a few days.

For anything in the theme itself, see the
[celadon-theme repo](https://github.com/celadon-theme/celadon-theme).
