Ports

Each port is plain files generated from the same source — install them, don't edit them. Available now for Ghostty, iTerm2, termic, Claude Code and oh-my-posh; more are on the way.

Terminals

Ghostty→

Drop the theme in ~/.config/ghostty/themes and set theme = celadon.
iTerm2→

Import the .itermcolors preset under Settings → Profiles → Colors.
termic→

Copy a theme into ~/.config/termic/themes — it shows up in the theme picker.
AlacrittyPlanned

Import the palette TOML from your alacritty.toml.

KittyPlanned

Include the .conf from your kitty.conf.

WezTermPlanned

Load the Lua palette in your wezterm.lua.

Editors

Claude Code→

Drop a theme in ~/.claude/themes, then pick it with /theme.
NeovimPlanned

Colorscheme plugin from the org, then colorscheme celadon.

VS CodePlanned

Install the Celadon extension and pick it in the theme switcher.

Shell & CLI

oh-my-posh→

Point oh-my-posh at celadon.omp.toml — variant-less, follows your terminal's ANSI.
tmuxPlanned

Source the theme snippet from your tmux.conf.

batPlanned

Add the theme to bat's config, then --theme=celadon.

deltaPlanned

Point delta's syntax-theme at Celadon for readable git diffs.

Don't see your app? Contribute a port — the generator makes it a few parameters, not a hand-tuned palette.
